# Руководство по реализации Frontend

Пошаговый план доработки фронтенда для интеграции с бэкендом API.

---

## Текущее состояние

Сейчас `frontend.html` работает на мок-данных (mockCtes, aggregatedCards). Нужно:
1. Заменить все мок-данные на реальные запросы к API
2. Добавить новые блоки для работы с характеристиками и объединением карточек
3. Реализовать логирование действий модератора

## API Endpoints, которые будут использоваться

### Карточки
| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/cards` | Список карточек |
| GET | `/api/cards/{id}` | Карточка с features и stes |
| POST | `/api/cards` | Создать карточку |
| PUT | `/api/cards/{id}` | Обновить карточку |
| DELETE | `/api/cards/{id}` | Удалить карточку |

### Характеристики
| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/cards/{id}/features` | Список характеристик |
| POST | `/api/cards/{id}/features` | Добавить характеристику |
| POST | `/api/cards/{id}/features/mark-insignificant` | Пометить незначимой |
| POST | `/api/cards/{id}/features/mark-significant` | Добавить в значимые |
| PATCH | `/api/cards/{id}/features/change-value` | Изменить значение |
| GET | `/api/cards/{id}/available-features` | Доступные характеристики |

### Объединение
| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/cards/merge-preview` | Предпросмотр объединения |
| POST | `/api/cards/merge` | Объединить карточки |
| GET | `/api/cards/{id}/merge-history` | История объединений |

## Модальные окна

### 1. Создание/Редактирование карточки
- Название
- Описание
- Категория

### 2. Объединение карточек
- Список карточек для объединения
- Выбор целевой карточки / Создать новую
- Конфликты характеристик
- Комментарий
- [Отмена] [Объединить]

### 3. История объединений
- Таблица с историей (дата, откуда, сколько СТЕ, модератор)

### 4. Изменение характеристики
- Название (readonly)
- Старое значение
- Новое значение
- Комментарий
- [Отмена] [Сохранить]
